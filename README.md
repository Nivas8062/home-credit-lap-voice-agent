# Home Credit Loan Against Property Voice Agent

## Project Overview
This project demonstrates an AI voice agent designed to screen customers for a Loan Against Property (LAP) offer using Retell AI.

## Objectives
- Verify the customer's identity.
- Collect the required loan qualification details.
- Identify eligible and ineligible applicants.
- Route existing-loan and EMI-reduction requests to the appropriate specialist.
- Hand off eligible applicants for further review.

## Eligibility Checks
- Property type: Residential, Commercial, or Industrial.
- Ownership: Sole or Joint.
- Original property documents must be available.
- Requested loan amount must not exceed ₹75 lakh, unless the customer accepts the maximum offer.
- Occupation: Salaried or Self-employed.
- Income must be received through a bank.
- Estimated property market value must be captured.
- Loan tenure must be between 3 and 15 years.

## Safety Rules
The agent must not claim loan approval, invent interest rates or fees, or request OTPs, PINs, passwords, or bank account details.

## Technology
- Retell AI
- AI voice-agent prompting
- Conversational qualification and routing
